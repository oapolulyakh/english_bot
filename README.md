# English Word Trainer Bot

Telegram-бот для изучения английских слов. Позволяет создавать собственный словарь, добавлять слова из готовых тематических наборов и тренировать запоминание с помощью викторины.

## ✨ Функционал

*   **Личный словарь:** У каждого пользователя своя изолированная база слов.
*   **Добавление слов:** Пошаговый ввод слова и его перевода. Защита от дубликатов.
*   **Тренировка (Quiz):**
    *   Бот предлагает слово на английском.
    *   Пользователь выбирает перевод из 4 вариантов (один верный, три случайных).
    *   При ошибке неправильный вариант исчезает, давая шанс угадать снова.
*   **Сборники (Presets):** Возможность добавить готовые паки слов по темам (IT, Путешествия, Базовый уровень).
*   **Управление:** Удаление конкретных переводов слов.

## 🛠 Технологический стек

*   **Язык:** Python 3
*   **Бот:** pyTelegramBotAPI (Telebot)
*   **База данных:** PostgreSQL
*   **ORM:** SQLAlchemy (Declarative Base)
*   **Конфигурация:** python-dotenv

## 🗄 Структура проекта

*   `main.py` — Точка входа. Основная логика бота, обработчики команд и кнопок.
*   `models.py` — Описание моделей базы данных SQLAlchemy (`User`, `Word`, `PresetWord`).
![Схема БД.png](%D0%A1%D1%85%D0%B5%D0%BC%D0%B0%20%D0%91%D0%94.png)
1. **Table `user`** (Пользователи)
   - `id` (PK, Integer): Уникальный идентификатор в БД.
   - `cid` (BigInteger, Unique): ID пользователя в Telegram.
   - `username` (String): Имя пользователя.

2. **Table `word`** (Словарь пользователя)
   - `id` (PK, Integer).
   - `word` (String): Английское слово.
   - `translation` (String): Перевод.
   - `user_id` (FK, Integer): Ссылка на таблицу `user`.
   *Связь: One-to-Many (Один пользователь имеет много слов).*

3. **Table `preset_word`** (Общие наборы слов)
   - `id` (PK, Integer).
   - `word` (String).
   - `translation` (String).
   - `category` (String): Название категории (например, 'IT', 'Travel').
   *Таблица справочная, не привязана к конкретным пользователям.*
*   `preset_words.py` — Логика наполнения базы данных начальными наборами слов (сидинг).
*   `.env` — Файл конфигурации с токенами и доступами к БД (должен быть создан пользователем).

## 📱 Пример использования

1.  **Начало работы:**
    Нажмите команду `/start`. Бот зарегистрирует вас в базе данных и покажет главное меню.
![Стартовое меню.png](%D0%A1%D1%82%D0%B0%D1%80%D1%82%D0%BE%D0%B2%D0%BE%D0%B5%20%D0%BC%D0%B5%D0%BD%D1%8E.png)
2.  **Наполнение словаря:**
    *   Если вы новичок, нажмите **"📚 Сборники слов"** и выберите категорию (например, *Travel*). Нажмите "Добавить ✅", чтобы скопировать слова себе.
    *   Чтобы добавить свое слово, нажмите **"➕ Добавить слово"**, введите слово на английском, а затем его перевод.
![Добавление сборника.png](%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%81%D0%B1%D0%BE%D1%80%D0%BD%D0%B8%D0%BA%D0%B0.png)
![Добавление слова.png](%D0%94%D0%BE%D0%B1%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%81%D0%BB%D0%BE%D0%B2%D0%B0.png)
3.  **Обучение:**
    Нажмите **"🎮 Тренировка"**. Бот будет показывать английские слова, а вам нужно выбрать правильный перевод.
    *   *Верный ответ:* Бот предложит продолжить.
    *   *Ошибка:* Бот уберет неправильный вариант, давая шанс исправиться.
![Режим тренировка.png](%D0%A0%D0%B5%D0%B6%D0%B8%D0%BC%20%D1%82%D1%80%D0%B5%D0%BD%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%B0.png)
4.  **Управление:**
    Используйте **"🗑 Удалить слово"**, чтобы убрать из словаря слова, которые вы уже твердо выучили.
![Удаление слов.png](%D0%A3%D0%B4%D0%B0%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D1%81%D0%BB%D0%BE%D0%B2.png)
